# Prediction Tracker

A full-stack web app for recording predictions, researching them with AI and tracking how they turn out.

## What it does

- Records each prediction with a probability, resolution date and resolution criteria
- Imports markets from Polymarket
- Organizes predictions with categories, tags, a dashboard and a calendar
- Shows analytics and an optional public profile
- Includes an AI thought partner for testing your reasoning
- Includes a demo mode with sample data
